# YouTube Clone (UI Demo)

A working YouTube interface clone built with a single HTML file — HTML, CSS and vanilla JavaScript. No frameworks, no build step.

## Features
- Video grid with thumbnails
- Category chips filtering
- Live search
- Modal video player with real playable sample videos
- Working like buttons

## Live Demo
https://raw.githack.com/ibrahimx305/Personal-portfolio/main/clones/youtube-clone/index.html

## Run it
Just open `index.html` in a browser.
